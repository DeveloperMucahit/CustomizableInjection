# CustomizableInjection

Bu proje, React Native kullanılarak geliştirilmiş bir WebView uygulamasıdır. Kullanıcıların web sayfasının arka plan rengini özelleştirmesine olanak tanır.

## Özellikler

- WebView içinde Google'ı görüntüleme
- Arka plan rengini özelleştirme
- Kullanıcı dostu arayüz
- Gerçek zamanlı renk değişikliği

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/yourusername/CustomizableInjection.git
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Uygulamayı başlatın:
```bash
npm start
```

## Kullanım

1. Uygulamayı başlattıktan sonra, metin kutusuna bir renk girin (örneğin: "red", "#ff0000", "lightblue")
2. "Change Background Color" butonuna tıklayın
3. WebView içindeki sayfanın arka plan rengi seçtiğiniz renge değişecektir

## Teknik Detaylar

- React Native WebView kullanılarak geliştirilmiştir
- JavaScript enjeksiyonu ile dinamik renk değişikliği sağlanır
- SafeAreaView ile güvenli görüntüleme alanı sağlanır
- TypeScript ile tip güvenliği sağlanır
